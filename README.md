# Mindstorms AG – Arena

Statische Website (HTML, CSS, JavaScript) mit Supabase als Datenbank und Anmeldung für Admins.

- `index.html`, `leaderboards.html`: öffentliche Seiten
- `login.html`, `admin*.html`: Admin-Bereich (Login nur für Admins)
- `js/config.js`: Supabase-URL und öffentlicher Schlüssel
- Veröffentlichen: jeder statische Host reicht (GitHub Pages, Render „Static Site“ mit Publish Directory `.`)
